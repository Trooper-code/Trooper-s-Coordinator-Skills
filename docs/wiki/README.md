# Wiki source

These files are the source of this repo's [wiki](https://github.com/Trooper-code/Trooper-s-Coordinator-Skills/wiki).
They live here too so the guide gets versioned, reviewed in pull requests, and copied with forks.

To publish changes to the wiki:

```
git clone https://github.com/Trooper-code/Trooper-s-Coordinator-Skills.wiki.git
# copy every .md from docs/wiki/ (except this README) into the wiki folder, then:
git add -A && git commit -m "Sync wiki from docs/wiki" && git push
```
